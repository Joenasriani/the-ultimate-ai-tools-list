# AI Tools Directory

A static, browser-based directory of AI products across creative and technical categories, with search, category navigation and pricing-tier filters.

**Project page:** https://joenasriani.github.io/the-ultimate-ai-tools-list/

## What is included

The single `index.html` file contains the interface, styles, JavaScript, and a hard-coded catalog of **139 tool records** as found during the source review.

Features implemented in the page:

- Search the catalog by tool information.
- Browse groups of tools by category.
- Filter the listed entries by their recorded `Free`, `Freemium`, or `Paid` tier.
- Open third-party product websites from the directory.
- Adapt navigation and cards for smaller screens.

## Run locally

Open `index.html` in a modern browser. There are no build steps, package dependencies, server calls, or account requirements in the inspected source.

## Scope and limitations

- This is a manually maintained catalog, not a live price or availability lookup service.
- The `Free`, `Freemium`, and `Paid` labels are **directory data**, not independently verified current prices. They do not establish commercial-use licensing rights.
- Tool features, names, links, and business models may have changed since the entries were written.
- All referenced products and trademarks belong to their respective owners.
- No automated link health, accessibility, or end-to-end deployment testing was performed as part of this documentation update.

This project is separate from the `list-of-ai-tools` repository, which uses multiple source files and a different dataset.
